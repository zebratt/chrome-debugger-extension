# 浏览器连续操作清理与合并计划

按已确认范围直接开发，不使用 SDD、TDD 或子代理流程。

## 交付范围

- 删除专用模型客户端、环境变量读取、模型决策循环、相关指标、测试和使用说明。
- `browser.run` 保留确定性的 search / navigate / fill，新增 `workflow: "sequence"` 与明确的 actions 列表。主模型规划步骤，本地顺序执行，每步重新观察并唯一匹配目标。
- 连续步骤支持 click、type、select、key、scroll、wait、assert；目标使用精确名称与可选 role / href 消歧，不执行生成的代码。
- 保留文档和目标守卫、焦点模拟、租约、新标签页跟随、加载等待、只读失效恢复；只有明确未执行的 stale 才恢复当前步骤，未知结果和未验证输入立即回交。
- 保留最终 URL / 文本 / 字段检查。返回已完成步骤数和下一步骤位置，防止重放已执行部分。没有最终条件时仅报告计划步骤执行完成。
- 删除模型自动决策专用的按钮确认分类；明确的动作清单沿用低级接口的调用者授权边界，skill 要求仅提交任务已授权的步骤。
- 同步 CLI、MCP、JSON Schema、文档及全局 skill；发布本机 0.4.0。
- 验证后将清理后的结果合并到 main，并同步远程。
